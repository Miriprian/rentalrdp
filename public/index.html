FAQ

Ini VPS / Proxmox virtual?

Bukan. Semua unit adalah komputer fisik (bare metal). Kamu dapat seluruh resource mesin selama sewa.

Bagaimana cara konek?

Windows: aplikasi Remote Desktop Connection (mstsc). Android: aplikasi RD Client Microsoft. Masukkan IP, user, password dari Dashboard.

Apakah boleh install aplikasi/game?

Boleh, selama legal & tidak melanggar hukum. Dilarang untuk judi, phising, DDoS, mining ilegal, dan konten ilegal.

Perpanjang sewa?

Bisa dari Dashboard → Rental Aktif → Perpanjang. Bayar selisih via WA admin agar tidak kehapus.
